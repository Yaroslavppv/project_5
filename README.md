# Платформа онлайн-обучения (Django REST Framework + Celery + Docker)

Проект представляет собой API-сервис для управления курсами, уроками и подписками с автоматизацией фоновых задач.

## 🚀 Инструкция по запуску через Docker

Для автоматической сборки образов, применения миграций и запуска всей инфраструктуры единой командой выполните в терминале:

```bash
docker compose up --build
```

После успешного запуска веб-сервер приложения станет доступен локально на порту **`8000`**. Вы можете тестировать эндпоинты API и интерактивную документацию (Swagger/Redoc) через локальный хост по адресу проекта.

## ⚙️ Переменные окружения (.env)
Перед запуском создайте файл `.env` в корневой директории проекта и заполните его по следующему шаблону:
- `CELERY_BROKER_URL=redis://redis:6379/0`
- `CELERY_RESULT_BACKEND=redis://redis:6379/0`
- `STRIPE_SECRET_KEY=ваш_секретный_ключ`
- `SECRET_KEY=ваш_django_secret_key`
